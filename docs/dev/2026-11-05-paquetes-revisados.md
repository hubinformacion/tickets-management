## Compatibilidad y publicación del mismo día

Next y eslint-config-next, React/DOM/tipos, TipTap y Tailwind se actualizaron como grupos coherentes. Googleapis 189 requiere Node >=22 y el entorno comprobado usa Node 24.22.1; el entrypoint Gmail/OAuth2 y las declaraciones usadas se conservan. Lucide 1 retira iconos de marcas; no se encontraron esos usos en TSX. Resolvers 7 sigue la API zodResolver usada y el conjunto pasó tipos. Dotenv 18 conserva config/quiet; no se ejecutaron scripts de BD o servicios reales para validarlo.

Los 40 selectores de minimumReleaseAgeExclude son **nombre@versión exacta**, limitados a lo publicado ese día: 30 paquetes TipTap, ocho Better Auth, resolvers y Lucide. Sin ellos, pnpm 11 rechaza incluso frozen con ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION. Se autorizaron como implementación del pedido expreso de actualizar hoy; no se desactiva la cuarentena para otros paquetes o versiones. Se conservan allowBuilds, ignoredOptionalDependencies y los tres overrides dirigidos previos. Instalación nueva, HOME vacío, lock congelado y scripts deshabilitados pasó sin variable que rebaje la antigüedad.

Typography publica un peer range `>=3.0.0 || >=4.0.0 || insiders` que el parser de semver rechaza por el literal insiders; al retirar ese literal, Tailwind 4.3.4 cumple el rango. Se documenta la advertencia upstream, sin ignorar peers globalmente ni cambiar CSS para silenciarla.

## Seguridad

Auditoría del árbol antes/después: **tres avisos moderados, cero altos/críticos**, sin afirmar ausencia de riesgos. Persisten esbuild 0.18.20 del loader legacy de Drizzle, UUID 8.3.2 de ExcelJS y minimatch 10.2.6 de herramientas ESLint. Los padres estables no suministran un parche compatible; no se imponen saltos mayores transitivos sin validación.

El uso inspeccionado de ExcelJS es uuid.v4() sin buffer, mientras el aviso exige otras variantes/uso de buffer. El loader esbuild inspeccionado transforma código de herramientas y no se encontró activación del servidor afectado en la aplicación. La llamada minimatch inspeccionada usa patrones de configuración local sin optimizationLevel>=2 exigido por el aviso. Son límites de alcance observados, no una garantía para usos distintos.
