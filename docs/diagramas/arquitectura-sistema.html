Plataforma de Gestión de Tickets

Diagrama estructural integral: Flujo de peticiones, separación por capas de confianza, orquestación mediante Server Actions en Next.js 16, persistencia PostgreSQL y sincronización con servicios Cloud.

Nodos Focales: Orquestador Server Actions & Core PostgreSQL Módulos de Aplicación: Controladores y lógica de negocio Integraciones Cloud: Gmail API, Google Drive & OAuth Identidad & Sesión: Better-Auth & Proxy Edge

Detalle de Componentes & Decisiones de Arquitectura

Orquestación Server Actions

Toda mutación y consulta pasa por Server Actions dedicadas en src/actions/, eliminando controladores REST redundantes y garantizando tipos TypeScript de extremo a extremo.

  • Autenticación estricta con requireAuth(), requireAgent() y requireAdmin().
  • Validación robusta con esquemas Zod en src/lib/validation/schemas.ts.
  • Resolución de waterfalls mediante Promise.all() concurrente.

Proxy & Seguridad de Borde

Implementación moderna con src/proxy.ts en Next.js 16 (reemplazo estandarizado de middleware.ts) para intercepción centralizada y protección perimetral.

  • Protección contra Redirect Loops en cookies expiradas.
  • Rate Limiting en memoria para tickets (10/min), comentarios (10/min) y admin (30/min).
  • Aislamiento de rutas /dashboard/(admin) y /dashboard/(agent).

Persistencia & Secuencias Atómicas

Neon PostgreSQL junto a Drizzle ORM garantizan integridad referencial y códigos autoincrementales sin colisiones por área y año.

  • Tabla ticket_sequence para generación atómica de {SLUG}-{YEAR}-{SEQ}.
  • Soporte multi-área fija: TSI, DIF y FED con SLA diferenciado.
  • Bitácora de estados completa en ticket_status_history.

Notificaciones & Almacenamiento Asíncrono

Integración de alto rendimiento con Google Workspace usando after() de Next.js para ejecuciones en segundo plano sin ralentizar la respuesta HTTP.

  • Gmail API con threading RFC (In-Reply-To, References) para 7 plantillas.
  • Google Drive API para adjuntos pesados en carpeta institucional.
  • Cron jobs automáticos para cierre de tickets validados y encuestas.
